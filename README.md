还在因为在手机上直接看学习资料而被家长发现而痛苦吗？
还在因为偷偷内卷被室友发现而尴尬吗？

## 📋 使用教程

### 第一步：安装 Python
前往 Python 官网或者国内镜像站点下载安装 Python。
>推荐版本：**Python 3.14 及以上**（本项目基于该版本开发测试）

### 第二步：安装依赖库
1. 按下快捷键 `Win + R`
2. 输入 `cmd` 回车，打开命令提示符窗口
3. 在黑色窗口中输入下面这条命令，回车执行
```bash
pip install fastapi uvicorn
```

等待下载安装进度跑完，第二步完成。

### 第三步：启动服务

> 
> 下文把运行这份程序的电脑称为「服务器」

1. 下载项目文件 `server2.py`
2. 右键 `server2.py`，选择用记事本（或其他文本编辑器）打开
3. 找到文件上方的**用户配置区**

```
# ============ 用户配置区 ============
ACCOUNTS = {
    "admin": {"pwd": "123456", "root": "./data/videos", "skin": "new"},
    "admins": {"pwd": "123456", "root": "./data/study", "skin": "old"}
}
RECYCLE_NAME = "$RecycleBin"
SYSTEM_FOLDER = "$system"
PORT = 8001
# ===================================
```

- `admin`：主账号，界面美观新版界面
  - `pwd` 后面引号内的 `123456` 为登录密码，支持英文、数字，可自行修改
  - `root`：网盘文件存放目录，**推荐填写绝对路径**，示例：`H:/a`
- `admins`：伪装账号，简约老式界面
  - `pwd` 后面引号内的 `123456` 为登录密码，支持英文、数字，可自行修改
  - `root`：网盘文件存放目录，**推荐填写绝对路径**，示例：`H:/b`

> 
> ⚠️ Windows 文件路径务必使用正斜杠 `/`，不要使用反斜杠 `\`

4. 修改完成后保存文件
5. 双击 `server2.py` 运行程序（如果弹出打开方式，请选择 Python）
6. **不要关闭弹出的黑色控制台窗口**，关闭则网盘服务停止

### 第四步：访问网盘

有两种访问方式：

1. **仅在服务器本机访问**：浏览器打开地址

```
http://127.0.0.1:8001
```

2. **局域网内其他设备（手机、平板、另一台电脑）访问**
   - 查询服务器电脑的内网 IP 地址
   - 在浏览器输入 `内网IP:8001`
   - 示例：`http://192.168.1.123:8001`
